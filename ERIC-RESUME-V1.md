## RESUME DELIVERY NOTES

**Format options for final export:**

1. **Google Doc** (easy to edit, Eric can export PDF). Recommended for iteration. Set to: Inter 11pt body, 14pt section heads, 22pt name, 0.75" margins, 1.15 line spacing. Name / title header in dark violet (#5D3FD3 or Level9 brand violet). Everything else black on white.
2. **Word .docx** (best ATS pass-through). Use Calibri 11pt if Inter isn't embedded. No tables except the role chronology table (ATS parses simple tables fine, not complex ones).
3. **PDF-from-docx** (recruiter-friendly). Never PDF-from-design-tool (Figma, Canva). Those break ATS.

**Do NOT:**
- Add icons, columns, or graphics. ATS parsers break on complex layouts.
- Use headers / footers / page numbers. ATS strips them inconsistently.
- Use Calibri Light, custom display fonts, or anything above 22pt.
- Add a photo. US resumes don't use photos and some ATS parsers fail on them.

**Length verification:** render as PDF at settings above and confirm 2 pages exactly. If it runs to 3, cut the "Continuous study" line in Education and compress the Build surface bullets to one line each. If it comes in under 2, add one more Level9 OS engagement bullet.
